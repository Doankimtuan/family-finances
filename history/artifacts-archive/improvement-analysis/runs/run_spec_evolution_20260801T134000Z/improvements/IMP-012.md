# IMP-012: Major: API versioning policy for public JSON routes

**Bucket:** Major Refactors  
**Priority:** P3  
**Estimated impact:** Medium-High scalability/compatibility

## Why

API design gap

## Current

Unversioned /api paths

## Problem

Hard to evolve envelopes without breaking clients

## Proposal

Introduce /api/v1 additive versioning; keep old paths as aliases until deprecated — no business change

## Expected Benefits

Safer evolution

## Trade-offs

Path duplication temporarily

## Risk

Medium

## Impact

Medium-High scalability/compatibility
