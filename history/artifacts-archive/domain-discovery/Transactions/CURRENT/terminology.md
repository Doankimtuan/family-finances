# Terminology

## Preferred Terms

| Term | Definition |
| --- | --- |
| Transaction | A factual record of real money movement. |
| Income | Money entering a household account or container. |
| Expense | Money leaving a household account or container. |
| Transfer | Money moving between accounts or people, requiring context to determine whether it is neutral, support, repayment, or spending. |
| Amount | Positive magnitude of money involved in the event. |
| Direction | Whether the amount entered or left the account. |
| Account | The real container affected by the transaction. |
| Transaction date | The date used for household review. |
| Posted date | The date the financial provider finalizes the statement line. |
| Pending | Visible but not final provider activity. |
| Posted | Final provider activity. |
| Counterparty | The other person, merchant, employer, provider, or institution involved. |
| Merchant | A counterparty selling goods or services. |
| Category | Household meaning assigned to the transaction. |
| Jar mapping | Link between a transaction fact and virtual planning intent. |
| Refund | Money returned in relation to a prior expense. |
| Reversal | A record that negates or unwinds a prior transaction. |
| Correction | A clarification record when prior transaction data was wrong. |
| Reconciliation | Comparing household records with bank, wallet, cash, or card reality. |
| Statement line | Provider's official transaction entry. |

## Forbidden Synonyms

| Avoid | Reason |
| --- | --- |
| Virtual transaction | Transactions are real money facts; virtual movement belongs to planning. |
| Budget transaction | Budgets and plans are intentions, not transaction facts. |
| Planned transaction | If money has not moved, it is a plan, bill, reminder, or forecast. |
| Fake transaction | Use correction, adjustment, or planning entry depending on context. |
| Balance movement for jar | Jar movement is virtual unless real money moved. |
| Delete history | Financial history should remain auditable as a business concept. |

## Business Definitions

- A transaction is factual before it is meaningful.
- A category explains purpose but does not change the fact.
- A jar mapping connects real activity to intention but does not move money.
- A refund is its own event connected to an earlier event.
- A correction explains record truth; it should not erase the existence of a prior mistake.
- A transfer may be neutral only when both sides belong to the household; otherwise it may be expense, income, support, loan, or reimbursement.
