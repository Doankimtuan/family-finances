# Terminology

## Preferred Terms

| Term | Business definition |
|------|---------------------|
| Card | A payment instrument issued by a card issuer for transactions under agreed terms. |
| Debit card | Card that spends from a linked payment account or overdraft limit. |
| Credit card | Card that spends against issuer-granted credit limit and creates repayment obligation. |
| Prepaid card | Card that spends from value loaded in advance. |
| Physical card | Tangible card form. |
| Virtual card | Non-physical card form represented electronically. |
| Tokenized card | Card credential provisioned into a wallet or merchant token. |
| Primary cardholder | Contracting cardholder responsible to the issuer. |
| Supplementary cardholder | Authorized user whose use is tied to primary-cardholder responsibility. |
| Card issuer | Institution issuing the card and setting user-facing terms. |
| Card acquirer | Institution enabling merchant card acceptance. |
| Card network | Domestic or international routing and rules network. |
| Merchant | Seller accepting card payment. |
| Authorization | Approval or reservation before final posting. |
| Posted transaction | Transaction recorded on the issuer-side card account. |
| Statement period | Time window summarized into a card statement. |
| Statement date | Date the issuer closes the statement period. |
| Statement balance | Amount due for a statement period. |
| Outstanding balance | Total unpaid issuer-recognized card obligation. |
| Minimum payment | Smallest required payment under issuer terms. |
| Payment due date | Deadline to pay required amount. |
| Available credit | Remaining spend capacity under the credit limit. |
| Credit limit | Maximum issuer-granted credit exposure. |
| Revolving balance | Credit-card amount carried after due date. |
| Cash advance | Cash or cash-like use of a credit card. |
| Refund | Merchant-initiated return of value to the card account. |
| Reversal | Cancellation or correction of a card transaction. |
| Chargeback | Formal dispute process involving issuer, network, acquirer, and merchant. |
| Cashback | Card reward credited as money or statement credit. |
| Installment | Scheduled repayment arrangement for a card purchase or balance. |
| Annual fee | Recurring issuer fee for holding the card. |
| Late fee | Fee charged after missed or late payment. |
| FX markup | Foreign-exchange cost added to cross-currency card use. |

## Forbidden Synonyms

| Avoid | Use instead |
|-------|-------------|
| Card balance, when referring to credit-card cash | Outstanding balance or statement balance |
| Free money | Credit limit |
| Bank balance, for credit card | Outstanding balance or available credit |
| EMI, without context | Installment |
| Swipe, as a generic term | Card transaction |
| Pay card, ambiguous | Card repayment or card purchase |
| Owner, for supplementary user | Supplementary cardholder |
| Debt, when specifically card-cycle debt | Card obligation |
| Cash back, inconsistent spacing | Cashback |

## Consistency Rules

- Use "credit card" only for revolving issuer credit.
- Use "debit card" only for access to payment-account money.
- Use "prepaid card" only for pre-funded stored value.
- Use "card repayment" for money paid to the issuer.
- Use "card purchase" for spending through the card.
- Use "statement balance" for the amount shown on a statement.
- Use "outstanding balance" for total unpaid card obligation.
