# Categories Domain Discovery

## Overview

Categories are household classification labels for money events. They answer what an income or expense was for, without holding money, setting limits, executing transactions, or becoming a plan.

This discovery focuses on Vietnam first, where young households commonly combine bank transfers, VietQR payments, cash, e-wallets, cards, online shopping, family transfers, salary income, and informal spending records.

## Purpose

This pack documents the real-world nature of Categories before any business, UX, architecture, database, or API design begins.

It is intentionally observational. It does not redesign ViNha, introduce requirements, create product decisions, or modify existing Sources of Truth.

## Scope

Included:

- Household income and expense classification.
- Category meaning, vocabulary, lifecycle, actors, boundaries, risks, and edge cases.
- Vietnam household practices and payment-context differences that affect category interpretation.
- Current factual product comparison based on existing artifacts and code.

Excluded:

- New product features.
- Implementation models.
- Database, API, or UX proposals.
- Official business-rule changes.
- Product decisions or roadmap commitments.
