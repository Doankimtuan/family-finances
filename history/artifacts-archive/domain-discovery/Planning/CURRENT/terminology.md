# Terminology

## Preferred Terms

| Term | Definition |
| --- | --- |
| Planning | The domain of household financial intention, expectation, allocation, and review. |
| Plan | A household intention for how money should be used over time. |
| Intention | A desired or expected use of money, not proof of real money movement. |
| Jar | A virtual purpose container for planned money. |
| Envelope | Real-world budgeting metaphor equivalent to a planning jar. |
| Allocation | Assignment of expected money to a purpose. |
| Planned amount | Amount intended for a purpose. |
| Capacity | Virtual room or planned availability inside an intention. |
| Goal | A target purpose with an amount, progress, and possible date. |
| Recurring rule | Expected repeating income or expense pattern. |
| Due date | Expected date when an obligation should be paid or reviewed. |
| Cash-flow pressure | Timing stress caused by expected inflows and outflows. |
| Month Ritual | Household review of a planning period. |
| Review | Human or household evaluation of plan versus reality. |
| Correction | Explicit update when planning information was wrong or incomplete. |
| Reallocation | Moving virtual planned capacity from one purpose to another. |
| Rollover | Unused planned capacity carried into a later period. |
| Assumption | A planning input that may not be provider-confirmed. |

## Forbidden Synonyms

| Avoid | Reason |
| --- | --- |
| Jar balance | Implies a jar is a real account balance. Use planned amount or capacity. |
| Virtual balance | Risks confusing intention with bank truth. |
| Planned transaction | If money has not moved, use plan, recurring rule, expected bill, or intention. |
| Budget transaction | Transactions are facts; budgets are plans. |
| Move money between jars | Use reallocate planned capacity unless real money moves through Accounts/Transactions. |
| Auto-pay | Planning expectation is not payment execution. |
| Confirmed bill | Use expected bill unless provider or transaction truth confirms it. |
| Savings balance for goal | A goal is intention; savings product balance belongs to Savings. |
| Debt balance in plan | Debt truth belongs to Loans or Cards. Planning may show repayment pressure. |

## Business Definitions

- Planning is virtual unless tied to confirmed real-world facts from another domain.
- A jar is a purpose, not a bank account.
- A goal is an intended outcome, not a provider-confirmed balance.
- A recurring rule is an expectation, not proof of payment.
- A month review creates household understanding, not bank truth.
- Reallocation changes intention; it does not move money.
- Real-world facts may inform Planning without becoming owned by Planning.
