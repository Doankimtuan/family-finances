# Mobile Strategy

## Primary experience

Smartphones are the primary target. Design and QA against phone viewports first.

## Rules

1. Bottom navigation with five IA items + Inbox badge  
2. Thumb-zone primary CTAs  
3. Safe-area padding for home indicator  
4. Single-column content  
5. Capture and Inbox optimized for one-handed use  
6. Touch targets ≥44×44px  
7. Scrolling matches a native app shell inside the viewport  

## Native feel

Treat the product as a mobile app delivered on the web: fixed chrome (top context + bottom nav), content scrolls between.
