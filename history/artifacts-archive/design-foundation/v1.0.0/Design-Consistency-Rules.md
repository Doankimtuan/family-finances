# Design Consistency Rules

Every future screen, component, and flow must feel like **one product: ViNha**.

## One language

1. One visual direction: **ViNha Calm Ledger**  
2. One accent: deep teal  
3. One radius scale, one type stack, one icon family (Phosphor)  
4. One nav model: five IA + Health chip  
5. One motion philosophy: sparse celebration  

## One money grammar

- Real vs intention visually and verbally distinct  
- Capture <15s pattern reused wherever expenses are added  
- Inbox card grammar reused for all ReviewItem kinds  

## One feedback grammar

- Error envelope → human recovery  
- Confirm+preview for destructive money  
- Fail closed offline  

## One collaboration grammar

- Partner-equal daily actions  
- Partner-visible policy changes  

## Enforcement

Before merge of UI work, pass **Future Design Checklist**. Design Foundation overrides legacy Rose Bloom docs. Product/Architecture/Tech Spec remain higher for scope/behavior; this pack is SoT for **how it looks and interacts**.
