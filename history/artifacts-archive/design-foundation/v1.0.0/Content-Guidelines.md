# Content Guidelines

## Voice

Calm adult. Collaborative. Precise. Honest.

## Glossary lock (must use)

Real Ledger / Money · Intention Plan / Plan · Jar · Inbox · ReviewItem · Month Ritual · Partner · Admin · Suggest / Auto · Financial Health

Forbidden as primary nav labels: Categories, Decision Tools, Dashboard (legacy), Accounts-as-IA-root.

## Money wording

- Jar amounts: “Planned” / “Intention” / “In jar” — **never** unlabeled “Balance” for jars  
- Ledger: “Available” / “In accounts” for real funds  
- Direction explicit: In / Out / Transfer  
- Overspend: state policy (Warn/Block/Allow) in words  

## Microcopy patterns

| Situation | Pattern |
|-----------|---------|
| Empty | What’s missing + next action |
| Error | What failed + how to fix |
| Confirm | What will change + Confirm / Cancel |
| Offline mutate | “You’re offline. Reconnect to save money changes.” |
| Suggest | “Suggested jar: {name}. Confirm or choose another.” |
| Ritual lock | “Approving locks plan movements for this month.” |

## Tone don’ts

- No shame (“You overspent again”)  
- No filler marketing (“Unleash”, “Seamless”, “Revolutionize”)  
- No em-dash flourishes as design voice  
- No fake-precise vanity metrics in UI  

## en / vi

- Same glossary concepts  
- Vietnamese may be longer — buttons and nav must wrap safely (prefer shorten labels, not shrink tap targets)  
- Currency/number formatting from household locale
