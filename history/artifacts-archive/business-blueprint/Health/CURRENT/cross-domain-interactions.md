# Cross-Domain Interactions

## Accounts

| Role | Description |
| --- | --- |
| Producer | Accounts produces real-money container visibility and balance context. |
| Consumer | Health consumes account visibility as a condition factor. |
| Ownership | Accounts owns account truth. |
| Responsibilities | Health must not edit accounts, infer hidden balances, or declare safe-to-spend amounts. |

## Transactions

| Role | Description |
| --- | --- |
| Producer | Transactions produces real money movement, recent activity, income/spending evidence, and category-linked events. |
| Consumer | Health consumes transaction rhythm and visible pressure evidence. |
| Ownership | Transactions owns transaction truth. |
| Responsibilities | Health must not create, correct, reconcile, or delete transactions. |

## Cards

| Role | Description |
| --- | --- |
| Producer | Cards produces credit/card burden, statement, repayment, and utilization context. |
| Consumer | Health consumes card pressure as a risk signal. |
| Ownership | Cards owns card product truth. |
| Responsibilities | Health must not change card state or initiate repayment. |

## Loans

| Role | Description |

## Savings

| Role | Description |

| Consumer | Health may consume visible savings context as resilience evidence. |
| Ownership | Savings owns savings product truth. |
| Responsibilities | Health must not deposit, withdraw, renew, close, or reinterpret savings product terms. |

## Planning

## Goals

| Role | Description |
| --- | --- |

## Inbox

| Role | Description |
| --- | --- |
| Producer | Inbox produces unresolved decision burden and decision rhythm context. |
| Consumer | Health consumes unresolved decision pressure. |
| Ownership | Inbox owns review item state and outcome. |
| Responsibilities | Health must not create, resolve, approve, reject, dismiss, defer, expire, or archive Inbox items. |

## Health

| Role | Description |
| --- | --- |
| Producer | Health produces condition, factor explanation, completeness context, and read-only scenarios. |
| Consumer | Other domains may display Health interpretation as context. |
| Ownership | Health owns interpretation only. |
| Responsibilities | Health must not become source truth or operational authority. |

## Categories

| Role | Description |
| --- | --- |

| Consumer | Health may consume category context as factor evidence. |
| Ownership | Categories owns classification meaning. |
| Responsibilities | Health must not create scoring-specific category truth or require category redesign. |
