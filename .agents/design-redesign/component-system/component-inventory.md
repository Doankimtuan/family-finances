# ViNha Component System — Master Component Inventory

## 1. Audit Scope & Source of Truth

This inventory is extracted from the 50 canonical screens designed across all 10 core ViNha product domains in Google Stitch (Project `16826760243481546078`):

1. **Home** (`SCR-01`): Dashboard, Net Available Assets hero, liquidity split, Inbox pulse, recent ledger feed.
2. **Money** (`SCR-02`, `SCR-03`): Money Overview, 4 financial pillars, Fast Add Transaction sheet with tabular VND input.
3. **Accounts** (`SCR-07`, `SCR-11` to `SCR-15`): Account groups (Bank, Cash, E-Wallet, Credit), Account Details, Add Account, Add Credit.
4. **Savings** (`SCR-08`, `SCR-16` to `SCR-20`): Term deposits, maturity timeline, provider catalog, settlement options.
5. **Investments** (`SCR-21` to `SCR-25`): Holdings roster, asset allocation, buy/sell sheets with MAX quantity helper.
6. **Bank Loans** (`SCR-26` to `SCR-30`): Institutional debt, repayment schedule, payment recording, debt payoff.
7. **Personal Lending / Borrowing** (`SCR-31` to `SCR-35`): Counterparty loans/debts, directional indicators, repayment recording.
8. **Plan** (`SCR-04`, `SCR-36` to `SCR-40`): 6-jar budgeting system, allocation adjustor, over-budget warnings, month-end review.
9. **Inbox** (`SCR-05`, `SCR-41` to `SCR-45`): Attention queue, unmapped transaction resolver, savings maturity decider, zero-pending state.
10. **Together** (`SCR-06`, `SCR-46` to `SCR-50`): Household hub, member directory, partner invite, shared planning policies, member departure sheet.

## 3. Consolidation Summary

- **Total Screens Audited**: 50 canonical screens across 10 product domains.
- **Total Components Inventoried**: 44 core primitives and composite patterns.
- **Inconsistencies Identified & Resolved**:
  1. _Touch target variance_: Standardized all interactive elements to ≥44×44px.
  2. _Border radius chaos_: Standardized into 5 strict tiers (10px controls, 12px cards, 16px overlays, 9999px pills, 50% circular avatars).
  3. _Financial numeral styling_: Unified on Geist tabular numerals (`tnum`) with explicit currency unit (`₫`).
  4. _Input height rhythm_: Unified on 48px standard input height across all 7 form domains.
  5. _Bottom sticky CTA clipping_: Standardized sticky form action container with 16px padding + `env(safe-area-inset-bottom)` and bottom scroll clearance.
  6. _Select dropdown absence_: Designed both closed trigger and open option list overlay with search capabilities.
  7. _Disabled vs Read-only_: Distinct visual treatments (Disabled = 45% muted; Read-only = 100% readable with informational styling).
