# Accounts Data Contract

Values are either direct query data or derived from the existing query result. No mock balances or fake account/card properties are introduced.

| Screen             | Direct data                                                                                                                           | Verified derived data                                                                                                                                       | Mock / logic pending | Missing / not applicable                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Accounts Overview  | `getRealPosition` account IDs/types/balances; `listCreditCards` debt, due, utilization, and attention fields; localized catalog names | Owned total and existing card presentation from `createMoneyHubViewModel`; directory group totals are sums of only the members of each existing asset group | 0                    | Provider/account-number metadata and account-prefilled transaction actions are not in the query/action contract              |
| Add Account        | Currency and linked asset account list from `listAccounts`; supported account types and icon keys from ledger constants/catalog       | None beyond shared currency display formatting                                                                                                              | 0                    | Bank/provider verification fields and an income transaction are N/A; opening balance is persisted by existing create command |
| Add Credit Account | Currency and active liquid accounts; schema-supported limit, statement day, due day, optional linked account                          | Initial card debt is the command's existing zero state                                                                                                      | 0                    | Existing debt is unsupported at creation; no issuer/network, autopay, or automatic reconciliation data                       |
| Asset Detail       | `getAccount`; recent transactions from `listRecentTransactions`; current financial-scope/owner facts                                  | Current balance is returned by ledger query; transaction type display is resolved from the explicit type                                                    | 0                    | No separate opening-balance transaction or new metric                                                                        |
| Credit Detail      | Card account, credit detail, billing months/items, installments, eligible purchases, recent activity                                  | Existing credit-facility availability/utilization is returned/validated by existing presentation helpers                                                    | 0                    | No invented payment forecast or initial debt                                                                                 |
| Edit / Archive     | Initial name/type/icon and `canMutate`; command results                                                                               | None                                                                                                                                                        | 0                    | Balance edits, hard delete, and account close are N/A                                                                        |

### Data flow

- Route Server Components authenticate and load application queries.
- Client forms call existing server actions; they do not call Supabase directly.
- Shared formatters handle localized currency/date output.
