## Route notes

- Asset and credit details share `/money/accounts/[id]`; the data type selects the composition.
- `/money/cards/[id]` currently redirects to loans and remains untouched.
- The handoff screen checklist's old SCR-12 `/money/cards/:id` route is stale; this implementation records the actual Accounts detail route above.
- New route constants live in `modules/shared-kernel/app-path.ts`. No Supabase schema or command contract changed.
