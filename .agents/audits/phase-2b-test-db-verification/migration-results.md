## Local validation implemented

Before inserts, the helper validates that input is an array with one object per loan term, that the loan belongs to the supplied household, JSON fields have the expected scalar types, installment sequence is a whole number and contiguous, amounts are nonnegative integer VND, installment totals and running balances reconcile, due dates follow the existing monthly schedule anchor, totals match the loan row, and the final balance is zero. Requiring JSON numbers prevents string values such as `"NaN"` from being cast into PostgreSQL numeric special values. Database constraints continue to enforce row-level nonnegative values, positive sequence numbers, uniqueness, and foreign keys.

This is static/source review only. It does not prove runtime execution, rollback, RLS behavior, or the wrapper's call path against PostgreSQL.
