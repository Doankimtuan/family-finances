# ViNha Engineering Knowledge Base

This folder contains the official long-term implementation knowledge base.

## Official Folders

- `current/specification/` — permanent implementation reference for product definition, architecture definition, technical specification, developer constitution, business rules, requirements, acceptance criteria, and glossary.
- `current/domains/` — consolidated domain packages. Each domain keeps final outputs from the approved phase sources without rewriting business content.
- `current/product/` — financial system integration, product experience, and financial invariants references.
- `current/planning/` — implementation roadmap, sprint plan, epic catalog, story catalog, and Definition of Done.
- `current/architecture/` — long-term engineering references derived from approved current sources.
Historical boards and previous artifact packs are excluded from the current
repository. The pre-cleanup safety branch preserves the prior state.

## Navigation

Start with `current/specification/README.md`.
Then open the relevant package in `current/domains/<domain>/`.
Use `current/product/` and `current/architecture/` only for cross-domain or system-level implementation questions.
Use `current/planning/` for roadmap and delivery sequencing.
