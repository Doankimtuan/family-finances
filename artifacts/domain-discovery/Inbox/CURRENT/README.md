# Inbox Domain Discovery

## Overview

Inbox is the household's queue of unresolved financial decisions. It answers: what real-world event, reminder, or imported fact needs human review before the household's records and intentions can stay trustworthy?

This discovery focuses on Vietnam first, where young households commonly receive financial signals through bank apps, VietQR transfers, e-wallets, SMS/OTT messages, email receipts, e-invoices, bill reminders, salary notices, and manual receipts.

## Purpose

This pack documents the real-world nature of Inbox before any business, UX, architecture, database, or API design begins.

It is intentionally observational. It does not redesign ViNha, introduce requirements, create product decisions, or modify existing Sources of Truth.

## Scope

Included:

- Pending household financial decisions.
- Unreviewed transaction facts, reminders, maturity prompts, correction needs, missing context, and read-only provider information.
- Household review behavior and decision avoidance.
- Boundaries with Transactions, Accounts, Cards, Savings, Loans, Planning, Notifications, Tenancy, and external providers.
- Current factual product comparison based on existing artifacts and code.

Excluded:

- New product features.
- Implementation models.
- Database, API, or UX proposals.
- Official business-rule changes.
- Product decisions or roadmap commitments.
