# Terminology

## Preferred Terms

| Term | Definition |
| --- | --- |
| Inbox | The household's queue of unresolved financial attention. |
| Review item | A single item requiring household review or decision. |
| Source event | The transaction, reminder, maturity, provider message, or internal event that caused the item. |
| Pending | Awaiting household attention. |
| Resolved | Household decision has been made. |
| Acknowledged | Household has recognized the item and no further Inbox action is needed. |
| Dismissed | Household intentionally removed the item from active attention. |
| Expired | Time made the item no longer active. |
| Archived | Historical, no longer active Inbox item. |
| Decision | A household choice that affects records, planning, or accountability. |
| Attention | The reason the item must be seen or reviewed. |
| Evidence | Receipt, invoice, provider message, transaction details, or other source context. |
| Stale item | An item whose usefulness declines because it has waited too long. |
| Review history | Record of past Inbox processing. |
| Auto-resolved | Resolved based on a prior accepted pattern or high-confidence rule. |

## Forbidden Synonyms

| Avoid | Reason |
| --- | --- |
| Notification | Too broad; many notifications do not require decisions. |
| Task | Implies generic productivity work rather than financial decision. |
| Message | Confuses Inbox with communication. |
| Alert | Implies urgency even when the item is calm review work. |
| Todo | Too generic and not financially precise. |
| Mark as read | Reading is not the same as resolving. |
| Delete | Historical financial attention should not be confused with deletion. |
| Clear | Ambiguous unless used as "Inbox zero" after resolution. |
| Feed | Implies passive stream rather than active queue. |

## Business Definitions

- Inbox is about unresolved attention, not all financial information.
- A review item should have a source, a reason, a state, and an outcome.
- Resolution is not necessarily money movement.
- Acknowledgement is weaker than resolution.
- Dismissal is an intentional exit from active review.
- Expiration is time-based exit, not proof that the underlying obligation disappeared.
- Archived items are historical context, not active work.
