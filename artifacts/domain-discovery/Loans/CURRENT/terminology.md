# Terminology

## Preferred Terms

| Term | Business definition |
|------|---------------------|
| Loan | A borrowing obligation with identifiable lender, principal, and repayment expectation. |
| Scheduled loan | A loan with known due dates or planned repayment periods. |
| Lender | The party owed money. |
| Borrower | The party obligated to repay. |
| Principal | The amount borrowed, excluding interest unless fees are capitalized into the loan. |
| Remaining principal | Principal still owed. |
| Outstanding balance | Total current obligation as recognized by lender; may include principal, interest, fees, or penalties. |
| Interest | Cost of borrowing over time. |
| Interest rate | Rate used to calculate interest. |
| Fixed rate | Rate that does not change during the relevant period. |
| Floating rate | Rate that can change according to provider policy or formula. |
| Promotional rate | Temporary preferential rate before another rate applies. |
| Repayment schedule | Planned sequence of due dates and amounts. |
| Installment | A scheduled periodic payment. |
| Due date | Date a payment is expected. |
| Payment | Real repayment event from household to lender. |
| Early payoff | Settlement before planned end date. |
| Prepayment fee | Fee for paying early. |
| Overdue | Payment has not been made by due date. |
| Default | Serious failure to repay according to terms. |
| Restructure | Changed repayment terms due to agreement or hardship. |
| Refinance | Replacing an obligation with a new loan. |
| Collateral | Asset pledged to secure repayment. |
| Guarantor | Person responsible if borrower fails to repay. |

## Forbidden Synonyms

| Avoid | Prefer | Reason |
|-------|--------|--------|
| Card | Loan | Credit cards are a separate revolving-credit domain. |
| EMI | Installment or scheduled payment | EMI is not universally understood and can imply a specific convention. |
| Balance | Remaining principal or outstanding balance | Balance is ambiguous without specifying principal-only or total lender balance. |
| Bill | Due payment | Bill can refer to utility, card statement, invoice, or loan payment. |
| Expense | Loan payment | A repayment is a money movement plus liability reduction, not only consumption expense. |
| Debt | Loan | Use Debt for open-ended owed money without schedule. |
| Plan | Repayment schedule | Plan can be confused with virtual budgeting. |
| Free installment | Interest-free installment | "Free" hides possible fees or purchase-price effects. |

## Consistency Notes

- Use `loan` for the obligation.
- Use `payment` only for real repayment events.
- Use `schedule` only for planned or agreed future obligations.
- Use `remaining principal` when discussing principal reduction.
- Use `outstanding balance` when referring to lender-recognized total obligation.
- Use `credit-card balance` only inside the Cards domain.
