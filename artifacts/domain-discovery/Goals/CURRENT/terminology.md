# Terminology

## Glossary

| Preferred term | Business definition |
| --- | --- |
| Goal | A named household intention for a future money-related outcome. |
| Goal purpose | The real-life reason the goal exists. |
| Target amount | The estimated amount needed for the goal outcome. |
| Target date | The date when the goal becomes relevant or desired. |
| Funded amount | The amount the household currently interprets as progress toward the goal. |
| Progress | The relationship between funded amount and target amount. |
| Contribution | A recorded increase in goal progress or intention. |
| Active goal | A goal currently being pursued. |
| Paused goal | A goal intentionally not being advanced for now. |
| Completed goal | A goal whose target or intended outcome has been reached. |
| Cancelled goal | A goal the household no longer intends to pursue. |
| Emergency fund | A protection goal for unexpected shocks. |
| Sinking fund | A goal-like accumulation for a known future expense. |
| Goal evidence | Read-only money facts that may support or challenge goal progress. |

## Forbidden Synonyms

| Avoid | Reason |
| --- | --- |
| Goal balance | Implies a provider-confirmed money balance. |
| Goal account | Confuses goal intention with Accounts or Savings. |
| Goal wallet | Confuses goal intention with wallet balance. |
| Available goal money | May imply spendable real money unless factual evidence exists. |
| Guaranteed progress | Goal progress may be manually interpreted. |
| Investment goal return | Moves into investment/advisory territory. |
| Debt balance goal | Debt truth belongs to Cards or Loans. |

## Business Definitions

- A goal is an intended outcome, not a money container.
- A contribution is a progress record, not necessarily a real transfer.
- A funded amount is interpreted progress, not necessarily verified cash.
- A target is an estimate, not a contract.
- A completed goal does not prove that a transaction occurred.
- A savings product can support a goal, but the savings product remains separate.
