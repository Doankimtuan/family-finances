# Current Source of Truth

`artifacts/current/` is the only implementation-facing documentation root.

## Folders

- `specification/` — official synchronized specification pack.
- `domains/` — approved domain packages.
- `product/` — system integration, product experience, and invariant references.
- `planning/` — delivery planning references.
- `architecture/` — long-term engineering references.
- `CHANGE_POLICY.md` — rules for future documentation changes.

Historical source packs are excluded from this repository and must not be used
as implementation authority.
