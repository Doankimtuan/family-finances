## Constitutional safeguards

- Real ledger money is separate from virtual Jar allocations.
- AI explains verified data but never invents balances or executes money
  movement without authorization.
- Health is read-only and never writes or executes money movement.
- The primary navigation is Home, Money, Plan, Inbox, and Together.
- Every implementation task must map to current specification and acceptance
  criteria.
