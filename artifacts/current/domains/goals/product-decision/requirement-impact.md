# Requirement Impact

This document identifies requirement impacts only. It does not create or rewrite requirements.

## New Requirements

| Candidate requirement area | Affected capabilities | Impact |
| --- | --- | --- |
| Goal intention language | GOAL-PD-004, GOAL-PD-005, GOAL-PD-007 | Requirements should distinguish goal progress from real balance. |
| Goal lifecycle meaning | GOAL-PD-006, GOAL-PD-010 | Requirements should define active, paused, completed, and cancelled as intention states. |
| Read-only goal evidence | GOAL-PD-013, GOAL-PD-018 | Requirements should state that evidence from money domains is read-only. |
| Goal purpose context | GOAL-PD-001, GOAL-PD-008, GOAL-PD-015 | Requirements should preserve simple household meaning. |
