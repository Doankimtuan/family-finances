# Together Product Decision Board

## Overview

This board makes product decisions for the Together domain based on:

- Phase 1 Domain Discovery.
- Phase 2 Household Reality Validation.
- ViNha product principles.
- Existing frozen Product Definition and domain artifacts.

Together is treated as the household trust boundary. It defines who belongs to shared finance, which household assumptions apply, and how partner-visible policy context is understood.

This pack does not modify any Source of Truth.

## Decision Process

The board reviewed every discovered Together capability from Phase 1 and Phase 2.

Each capability was classified as:

- APPROVED.
- APPROVED WITH MODIFICATIONS.
- DEFERRED.
- REJECTED.

No capability remains undecided.

## Decision Criteria

Decisions optimize for:

- Simple before powerful.
- Household-first collaboration.
- Real Ledger does not become Virtual Planning.
- Health remains read-only.
- No unnecessary automation.
- User clarity about where money is and who can see it.
- Financial and relational safety over convenience.
- Maintainability over 5-10 years.
