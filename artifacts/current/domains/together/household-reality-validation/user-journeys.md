# User Journeys

## Happy Path

1. One partner creates a household financial space.
2. The other partner accepts the shared boundary.
3. Both understand who belongs and what shared visibility means.
4. Household policies are visible and stable.
5. Other domains use the household boundary consistently.
6. Material changes are noticed before they cause conflict.

Behavioral validation:

- This matches households that already discuss money openly.
- Together solves a real problem by making shared participation explicit.

## Common Path

1. One partner starts because they are already managing money.
2. The second partner joins later or engages lightly.
3. The household uses the shared view unevenly.
4. The active partner updates policies or records.
5. The less-engaged partner checks summaries or asks questions during stressful moments.

Behavioral validation:

- This is likely the most realistic path for young households.
- Asymmetric engagement is normal, not failure.

## First-Time Usage

1. User decides whether this product is for personal tracking or household management.
2. User names the household.
3. User decides whether to invite the partner.
4. Partner decides whether joining feels safe and useful.
5. Both partners begin forming expectations about visibility.

Behavioral validation:

- The concept is understandable if framed around "our household."
- Trust can be lost early if membership feels like control or surveillance.

## Long-Term Usage

1. Household keeps using the same shared boundary month after month.
2. Income, accounts, bills, and family obligations change.
3. Policies become background assumptions.
4. Members rely on Together indirectly through Money, Plan, Inbox, and Health.
5. Household revisits Together only when people, policies, or preferences change.

Behavioral validation:

- Together should be quiet infrastructure most of the time.
- Long-term value comes from stability and shared trust, not frequent interaction.

## Recovery Path

1. Invitation fails, expires, or is sent to the wrong email.
2. Partner does not join or joins with confusion.
3. Household policy changes create misunderstanding.
4. Member access, device access, or relationship status changes.
5. Household must re-establish who belongs and what remains shared.

Behavioral validation:

- Recovery is partly technical and partly relational.
- Edge cases are emotionally heavier than normal setup.

## Exit Path

1. A member stops participating.
2. Household separates, pauses, or closes shared management.
3. Historical records still matter.
4. Former access and responsibility become sensitive.

Behavioral validation:

- Exit is a real household need over 5-10 years.
- It is lower-frequency but high-risk.
