# Deferred Features

## Deferred Capabilities

| ID | Capability | Reason | Conditions to reconsider | Suggested future phase |
| --- | --- | --- | --- | --- |
| CAT-PD-015 | Merge category meaning | Real duplicate-label issue, but historical interpretation risk is high. | Evidence of frequent duplicate categories and validated user understanding of report effects. | Version 1.x or Version 2.x. |
| CAT-PD-016 | Split mixed transaction across categories | Mixed purchases are real, but complexity and category/jar interaction are high. | Evidence that mixed purchases materially distort household decisions and users tolerate added work. | Version 1.x or Version 2.x. |
| CAT-PD-017 | Category visual identity | Helpful scan aid, but not core financial correctness. | Stable category vocabulary and design-system readiness. | Version 1.x. |
| CAT-PD-019 | Detect duplicate or near-duplicate categories | Useful after category growth; premature before real vocabulary evidence. | Real usage shows duplicated category clutter. | Version 2.x. |
| CAT-PD-020 | Track confidence for inferred labels | Depends on inferred or imported categorization maturity. | Suggested categorization is active enough to need uncertainty language. | Version 2.x. |
| CAT-PD-022 | Merchant-to-category learning | Valuable but automation-sensitive and provider-dependent. | Merchant identity and override behavior validated with Vietnam household data. | Version 1.x or Version 2.x. |
| CAT-PD-023 | Vietnamese merchant normalization | Strong future value but requires descriptor research. | Provider descriptor sampling across banks, wallets, cards, and VietQR. | Version 2.x. |
| CAT-PD-024 | Receipt-line or item-level classification | Too detailed for simple-first household use. | Receipt evidence becomes common and mixed-purchase pain is validated as high. | Future. |
| CAT-PD-025 | Household category templates by life stage | Plausible, but local vocabulary needs research. | Vietnamese card-sorting validates repeated life-stage taxonomies. | Version 2.x. |
| CAT-PD-026 | Cross-provider category reconciliation | Requires multiple provider categories and import maturity. | Provider integrations create conflicting category evidence at meaningful volume. | Future. |
| CAT-PD-027 | Longitudinal category drift detection | Long-term concern but not early user value. | Multi-year category histories show report confusion from meaning drift. | Future. |
| CAT-PD-028 | Category portability for export or adviser review | Low current validation for target households. | Users need adviser, accountant, export, or migration interpretation. | Future. |
| CAT-PD-029 | International or multi-currency category context | Outside Vietnam-first VND core. | Travel, remittance, or multi-currency usage becomes common in target households. | Future. |

## Deferral Principle

Deferred capabilities are not rejected. They are postponed because simple-first household comprehension and financial safety outweigh early power.
