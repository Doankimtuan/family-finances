# User Journeys

## Happy Path

1. A user records or reviews a transaction.
2. The transaction context is recognizable.
3. The user selects a category that both partners understand.
4. Later, the household reviews spending by category.
5. The category summary matches their memory of the month.
6. The category remains useful for planning conversation.

Behavioral validation: This journey matches ordinary household behavior. People naturally say "food", "rent", "Grab", "baby", or "parents" when explaining spending.

## Common Path

1. Spending happens across cash, bank, wallet, card, or VietQR.
2. Some transactions are obvious and categorized quickly.
3. Some transactions are unclear because the merchant, note, or memory is weak.
4. One partner asks the other what the transaction was for.
5. The household accepts approximate classification for small transactions.
6. A monthly review reveals patterns and a few wrong or missing categories.

Behavioral validation: This is the realistic default. Perfect categorization is uncommon; "good enough" categorization is common.

## First-Time Usage

1. The household sees a default or initial set of categories.
2. Users look for familiar words such as food, transport, home, health, salary, or other.
3. They classify recent transactions based on memory.
4. They may create or expect categories for local life events such as parents, Tet, wedding, baby, school, or delivery.
5. Confusion appears if categories look like budgets or jars.

Behavioral validation: Users understand labels quickly, but the boundary between category and planning container requires care.

## Long-Term Usage

1. Categories become household shorthand.
2. Recurring merchants become mentally tied to categories.
3. Category totals support month-end reflection.
4. New life stages create new classification needs.
5. Old categories may become inactive, duplicated, or renamed.
6. Historical comparison becomes useful but fragile if category meaning drifts.

Behavioral validation: The model can last, but vocabulary maintenance becomes more important over years.

## Recovery Path

1. A transaction is uncategorized, miscategorized, or disputed.
2. The user reviews the transaction context.
3. The household checks bank note, receipt, merchant, chat, or partner memory.
4. The category is corrected or left unknown.
5. The corrected meaning changes later interpretation.

Behavioral validation: Recovery is normal. Users expect mistakes and corrections, especially for cash, marketplace purchases, and family transfers.

## Abandonment Path

1. Too many transactions require manual categorization.
2. Category choices feel repetitive or unclear.
3. The household postpones review.
4. Uncategorized activity accumulates.
5. Category reports stop feeling trustworthy.

Behavioral validation: Manual work tolerance is a major risk for young busy households.
