# Inbox Product Decision Board

## Overview

This board records product decisions for the Inbox domain in ViNha.

Inbox is evaluated as the household's queue of unresolved financial attention: a place where real-world signals become clear decisions without becoming a transaction ledger, notification center, task manager, or automation engine.

## Decision Process

Inputs reviewed:

- `artifacts/domain-discovery/Inbox/CURRENT/`
- `artifacts/household-reality-validation/Inbox/CURRENT/`
- Existing Inbox philosophy, implementation-contract, screen-blueprint, and technical-specification artifacts.

The board reviewed every discovered capability from Phase 1 and Phase 2 and classified each as:

- APPROVED
- APPROVED WITH MODIFICATIONS
- DEFERRED
- REJECTED

## Decision Criteria

Every decision was tested against:

- Simple before powerful.
- Household-first.
- Real Ledger != Virtual Planning (BR-01).
- Health is read-only (BR-24).
- No unnecessary automation.
- User always understands where money is.
- Financial safety over convenience.
- Maintainability over 5-10 years.
