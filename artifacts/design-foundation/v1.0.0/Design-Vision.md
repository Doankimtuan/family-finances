# Design Vision

## Product

**ViNha** — shared money OS for couples and families that separates **real money** from **monthly intention**.

## Brand Personality

Calm · Adult · Collaborative · Precise · Honest · Grounded

ViNha is a quiet co-pilot for household money, not a bank billboard, not a gamified scoreboard, not a spreadsheet cosplay.

## Product Personality

| Trait | Expression |
|-------|------------|
| Calm | Sparse chrome, no alarmist defaults, sparse celebration |
| Truthful | Real Ledger and Intention Plan never visually conflated (BR-01) |
| Partner-aware | Equal daily agency; policy changes are partner-visible |
| Progressive | Depth on demand; onboarding ≤3 steps |
| Ritual-respecting | Month Ritual feels like ceremony, not a settings checkbox |

## Brand Values

1. Clarity over cleverness  
2. Shared trust over sole-operator power  
3. Intention without fiction  
4. Accessibility as default quality  
5. Automation with receipts  

## Emotional Goals

Users should feel: oriented, respected, capable together, and never shamed.

Users should not feel: audited by the app, confused about “where the money went,” or alone with household money.

## User Feelings (target)

| Moment | Feeling |
|--------|---------|
| Open Home | “I know what we have, what we meant, what’s next.” |
| Capture expense | Fast, friction-light, done in one breath |
| Inbox card | One clear decision; not a pile of archaeology |
| Month Ritual | Shared ceremony; lock is intentional |
| Error / offline | Honest, recoverable; never silent money failure |

## Product Voice

**Calm adult voice.** Speak like a capable partner explaining money, not a coach yelling KPIs.

## Tone

- Direct, warm enough for households, never cute  
- Prefer concrete nouns (Jar, Inbox, Month Ritual) over marketing verbs  
- Sparse celebration: ritual complete, goal hit, EMI complete only  

## Writing Style

- Short sentences; one idea per line in UI  
- One primary CTA per screen  
- Numbers with tabular figures; amounts never ambiguous about direction  
- Teach real≠virtual in Plan and Home labels, not footnotes buried in Settings  

## Communication Principles

1. Name the thing with Product glossary terms  
2. Prefer verbs that match actions (Add expense, Resolve, Approve ritual)  
3. Never present jar totals as bank balance  
4. Never invent money in copy (aligns BR-14 for Phase 2 AI)  
5. Failures are spoken; successes may be quiet unless ritual/goal/EMI  

## Microcopy Principles

- Labels above inputs; placeholders never replace labels  
- Errors: what happened + what to do next  
- Confirmations: preview impact before irreversible money/plan locks  
- Offline: fail closed for mutations — say online is required (BR-15 / REQ-018)  
- en/vi: same meaning, household locale for money format
