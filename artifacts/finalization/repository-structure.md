# Repository Structure

## Official

```text
artifacts/
  current/
    specification/
    domains/
    planning/
    architecture/
    product/
    CHANGE_POLICY.md
  finalization/
  README.md
  index.json
history/
  artifacts-archive/
  compressed/
```

`artifacts/current/` is the only implementation-facing documentation root.
`history/` is immutable reference material.
