# ViNha Stitch icon atlas

Stitch generated 13 contact sheets covering the 271 semantic icon entries in [`../DESIGN.md`](../DESIGN.md), plus sheet 14 with mail, sun, and moon. Open `index.html` to browse the set, or open any numbered sheet directly. Each sheet contains inline SVG artwork and 24 px / 16 px examples.

The source Stitch project is [ViNha Mobile Finance Icon System](https://stitch.withgoogle.com/projects/16826760243481546078). Stitch MCP saved all 13 screens, but the project canvas currently lists only some of them. This export preserves every generated sheet together.

App integration uses the extracted Stitch SVG artwork through `AppIcon`. Persist account and category icon keys, not SVG markup.
