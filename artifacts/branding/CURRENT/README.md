# ViNha Woven Path brand pack

The **Woven Path** mark uses two equal rounded paths interlocking around a clear center. It expresses household money held together: two people, one stable way forward, with clarity and room for what matters.

## Canonical source

The reusable in-app implementation is `shared/patterns/brand-mark.tsx`. The vector masters are in `assets/svg/`. Public raster and vector outputs are generated with `node scripts/generate-brand-assets.mjs`.

| Asset | Use |
|---|---|
| `assets/svg/mark.svg` | Full-color primary mark on light surfaces |
| `assets/svg/app-icon.svg` | Full-color square app icon |
| `assets/svg/favicon.svg` | Simplified browser favicon geometry |
| `assets/svg/maskable.svg` | Adaptive platform icon with safe padding |
| `assets/svg/monochrome.svg` | Single-color platform treatment |
| `assets/exports/app-icon-1024.png` | App-store master export |
| `assets/brand-board.png` | Brand-system reference board |
| `assets/brand-validation-sheet.png` | Rendered size validation evidence |

## Usage rules

The mark is designed to remain recognizable without the ViNha wordmark. Use the compact mark in application headers and the full identity treatment only where there is room, such as Welcome, authentication, onboarding entry, splash, and system fallback surfaces. Do not use the full mark-plus-wordmark lockup in navigation rows, buttons, or financial data surfaces.

The simplified favicon is the required small-size source and must be checked at approximately 16px, 32px, and 48px. The full-color treatment uses deep teal with a warm stone secondary band; the app icon uses an off-white primary band and hero-muted secondary band on the teal plate. The monochrome treatment uses the text-primary token equivalent. The mark must not depend on gradients, tiny internal details, currency symbols, or a literal home/wallet/piggy-bank silhouette.
