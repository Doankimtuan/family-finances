# IA Map

Every screen belongs to exactly one navigation group.

| Group | Screens |
|-------|---------|
| authentication | `auth.splash`, `auth.welcome`, `auth.login`, `auth.register`, `auth.forgot-password`, `auth.confirm` |
| health | `health.overview`, `health.insights` |
| home | `home.index` |
| inbox | `inbox.queue`, `inbox.review-detail`, `inbox.approval-detail` |
| money | `money.hub`, `money.transactions`, `money.transaction-detail`, `money.transaction-add`, `money.transaction-edit`, `money.accounts`, `money.account-detail`, `money.debts`, `money.debt-detail`, `money.savings`, `money.savings-detail`, `money.cards` |
| onboarding | `onboard.wizard` |
| plan | `plan.hub`, `plan.jars`, `plan.jar-detail`, `plan.goals`, `plan.goal-detail`, `plan.recurring`, `plan.recurring-detail`, `plan.month-ritual` |
| system | `system.error`, `system.offline`, `system.permission`, `system.maintenance` |
| together | `together.members`, `together.invitations`, `together.invite-accept`, `together.policies`, `together.preferences` |

Primary chrome tabs: Home · Money · Plan · Inbox · Together. Health via Home chip only.
