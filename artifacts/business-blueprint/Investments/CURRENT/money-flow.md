# Money Flow

## Real Ledger

Real Ledger money movement belongs to Accounts and Transactions.

Contribution:

```text
Bank / cash account
  -> real transfer transaction
  -> investment platform / seller / family recipient
  -> investment holding context
```

Sale or redemption:

```text
Investment holding
  -> sale / redemption / repayment / surrender
  -> real proceeds transaction
  -> bank / cash account
```

Investment income:

```text
Issuer / fund / bond / provider
  -> dividend / coupon / distribution
  -> real cash transaction
  -> account
  -> investment income context
```

Fees, spreads, and charges:

```text
Investment platform / provider / market
  -> fee or deduction
  -> real transaction when cash movement is known
  -> investment context explains why
```

Rules:

- Investments never posts cash movement by market value change alone.
- Transactions own real money movement facts.
- Accounts own where cash is held.
- Investments explains investment meaning.

## Planning

Planning may express intended investment contribution.

```text
Plan intention
  -> intended investment amount
  -> no investment exists until real cash movement and holding recognition occur
```

Rules:

- Planned contribution is not an investment holding.
- Unrealized investment value is not plan capacity by default.
- Investment purpose notes do not create goal progress or jar allocation.

## Inbox

Inbox may surface review-worthy investment uncertainty.

```text
Stale value / missing source / partner question / unclear proceeds
  -> review context
  -> household clarification
  -> Investments remains, corrects, exits, or archives
```

Rules:

- Inbox does not decide buy/sell/hold.
- Inbox does not move money.
- Inbox does not provide investment advice.

## Read-Only

Read-only information may include:

- Manual value.
- Provider statement.
- Market quote.
- Receipt.
- Family update.
- Partner disclosure.

```text
Information source
  -> estimated value + valuation date + source/confidence
  -> investment interpretation
```

Rules:

- Read-only value is not a transaction.
- Read-only value is not guaranteed proceeds.
- Stale or uncertain information must remain distinguishable from confirmed cash.
