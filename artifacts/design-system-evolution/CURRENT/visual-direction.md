# Visual Direction

## Canonical Direction

ViNha uses a visual language called Calm Household Finance.

It combines soft mobile-app surfaces, grounded financial labels, warm neutral space, deep teal action color, tabular money typography, and gentle feedback motion. The result should feel modern and emotionally safe without hiding the seriousness of real money.

## Visual Personality

- Light and calm by default.
- Warm without becoming beige craft branding.
- Trustworthy without looking like a bank back office.
- Slightly expressive through icons, state illustrations, rhythm, and small motion.
- Product-native, not marketing-page composed.

## Emotional Tone

The interface should feel like a steady household companion. It should reduce pressure, never shame spending, and never dramatize ordinary financial variance.

Warnings are factual and calm. Success feels acknowledged, not gamified. Empty states feel invitational, not promotional.

## Density

Use medium daily-app density. Screens should be spacious enough for comprehension and thumb use, but not sparse. Financial detail is progressive:

- Hubs show orientation and next actions.
- Lists show scannable facts.
- Details show source, meaning, and consequence.
- Confirmations show all relevant effects before commitment.

## Composition

Use a constrained mobile viewport as the product canvas. Compose with vertical sections, grouped rows, bottom action bars, and sheets. Avoid desktop dashboard habits inside the mobile shell.

Cards are reserved for bounded objects, actionable summaries, or repeated financial products. Sections and rows should do most of the organizing.

## Hierarchy

Each section should have one dominant meaning:

- One primary action per state.
- One dominant amount per section only when that amount is the point.
- Secondary amounts remain tabular but quieter.
- Warnings and stale labels sit near the fact they qualify.

## Contrast

Use clear text contrast for money and state labels. Use tonal contrast first, color second. Critical states must stand out, but ordinary overspend, stale data, and review needs should not look like emergencies.

## Whitespace

Whitespace should create relief and grouping. It must not create decorative emptiness. Use spacing to show relationships:

- Tight for label and value.
- Moderate for row groups.
- Generous between screen regions.
- Extra bottom padding when actions or navigation are fixed.

## Color

Color expresses semantic meaning, not module branding. Deep teal remains the primary action and savings/planning affinity color. Income, expense, caution, critical, informational, and domain states use semantic tokens only.

No random color per module. No neon finance aesthetics. No gradient-dependent readability.

## Motion

Motion is quiet and purposeful. It communicates feedback, continuity, expansion, completion, and state change. It never animates values in a way that makes money feel unstable.

## Icon Personality

Use one icon family consistently, preferably Phosphor. Icons should feel friendly, rounded, and legible at mobile sizes. Avoid overly cute, decorative, or symbolic icons for serious financial states.

## Illustration Personality

Illustrations may support onboarding, empty states, education, and milestones. They should be soft, contextual, household-centered, and abstract enough to localize well. They must never replace facts, amounts, source labels, or confirmation details.

## Data Visualization Personality

Charts should answer one practical question. Use minimal ink, direct labels, and text explanation. Avoid trading-terminal visuals, dense dashboards, decorative charts, and chart-only interpretation.

## Young, Flexible, Modern Finance

ViNha expresses youthfulness through language, rhythm, modern iconography, soft tonal surfaces, quick thumb-friendly action, and helpful progress moments. It stays durable by avoiding trend-first typography, neon gradients, meme language, emoji navigation, childish mascots, and decorative animation.
