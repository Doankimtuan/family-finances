# Design System Evolution - Current

Phase D defines the canonical visual system and UI implementation mindset for ViNha.

This package is governed by:

- Phase A redevelopment audit in `artifacts/redevelopment-audit/CURRENT/`
- Phase B information architecture in `artifacts/information-architecture/CURRENT/`
- Phase C UX redesign in `artifacts/ux-redesign/CURRENT/`
- Frozen product and business contracts in `artifacts/current/specification/`
- Current shared UI, shared patterns, HeroUI configuration, and semantic theme tokens

Phase D does not change business behavior, information architecture, navigation ownership, domain ownership, financial rules, or UX flow contracts.

## Canonical Direction

ViNha should feel like a Gen Z financial life companion for young Vietnamese households: calm, warm, mobile-native, flexible, and trustworthy. It should make financial facts easier to understand without becoming an accounting tool, bank back office, gamified app, crypto product, or marketing showcase.
