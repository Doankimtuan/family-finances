# Design Principles

These rules are mandatory and enforceable.

1. One primary purpose per screen.
2. One primary action per state.
3. One dominant number per screen section.
4. Important money movement is always visible before confirmation.
5. Real ledger money and virtual plan intention are visually distinct.
6. Every amount carries meaning, such as available, due, expected, estimated, realized, or unrealized.
7. Use cards only for actionable, repeated, or bounded content.
8. Prefer sections, groups, and rows over nested cards.
9. Use color for meaning, never decoration alone.
10. Never encode status by color only.
11. Use progressive disclosure for financial detail.
12. Prefer conversational clarity over banking terminology.
13. Avoid red for ordinary overspending feedback.
14. Label stale, partial, or estimated financial data next to the fact.
15. Success shows a receipt when money, plan, decision, or records changed.
