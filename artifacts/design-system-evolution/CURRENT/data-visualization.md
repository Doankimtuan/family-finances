# Data Visualization

## Principle

Each visualization answers one question.

Examples:

- "Are we on track?"
- "What changed this month?"
- "Where is money allocated?"
- "What is due soon?"
- "How fresh is this estimate?"

## Preferred Forms

- Progress bars.
- Simple line trends.
- Composition bars.
- Lightweight donut only when proportion is the main question.
- Timelines.
- Comparison rows.
- Sparkline with text explanation.

## Chart Rules

- Use minimal ink.
- Provide text explanation near the chart.
- Work in light and dark mode.
- Remain readable without color.
- Avoid financial-trading aesthetics.
- Label estimated values and freshness.
- Do not imply investment advice.

## Avoid

- Complex dashboards.
- 3D charts.
- Decorative charts.
- Too many metrics on one screen.
- Candlestick styling outside Investments.
- Chart-only conclusions.

## Implementation

Use Recharts when a chart is needed. Use semantic chart tokens. If a simpler row, bar, or timeline answers the question, do not add a chart.
