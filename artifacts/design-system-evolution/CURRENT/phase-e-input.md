# Phase E Input

Phase E may implement screens using this design system.

## Required Inputs Before Implementation

- Phase B IA.
- Phase C UX flow and state model.
- Phase D visual system.
- Current shared component inventory.
- Target route and owner module.
- Current browser screenshot at 440px.

## Priority Component Gaps

Phase E should consider adding these only when implementing a screen that needs them:

- Page.
- Section.
- Stack.
- Inline.
- Surface.
- BottomActionBar.
- MoneyField.

- DateField.

- InlineMessage.
- SuccessState.
- ConfirmDialog.
- FinancialPreview.
- MoneyMovementPreview.
- BalanceRow.
- ScheduleRow.
- MaturitySummary.
- InvestmentSummary.

## Required Evidence Per Screen

- Browser screenshot at 440px.
- Light mode screenshot.
- Dark mode screenshot.
- Keyboard or form behavior check where applicable.
- English and Vietnamese fit check.
- Accessibility notes for focus, labels, and contrast.

## Non-Goals

Do not implement a complete design-system rebuild before screen work. Promote components as the implementation proves repeatable.
