# Visual Foundation

## Foundation Summary

ViNha uses semantic tokens, Geist typography, HeroUI-backed primitives, Phosphor icons, and a constrained mobile app canvas.

Design dials:

- Design variance: 4 of 10
- Motion intensity: 3 of 10
- Visual density: 5 of 10

## Typography

Use Geist Sans for product UI and Geist Mono only for technical identifiers, debug values, and rare compact metadata. Money amounts use tabular numerals.

Display scale is restrained. Product headings should not become marketing hero type inside app screens.

## Spacing

Use the existing 4px base scale:

- 4px: tight label relationships.
- 8px: field internals and small row gaps.
- 12px: compact stack rhythm.
- 16px: standard screen padding and list rhythm.
- 20px: form step rhythm.
- 24px: section rhythm.
- 32px: large section separation.
- 40px and 48px: special top-level screen breathing room.
- 64px: rare flow separation or empty-state composition.

## Shape

Use a soft but disciplined radius system:

- Controls: 10px.
- Cards: 12px.
- Sheets and dialogs: 16px.
- Pills: only for navigation chips, compact filters, and state labels that need capsule affordance.
- Icon containers: 10px or circular only when the icon represents a person/avatar/status mark.

## Elevation

Prefer border, tonal surface, and spacing over shadows. Shadows are allowed for the phone viewport, dialogs, sheets, toasts, and rare elevated action surfaces.

## Color

Use semantic tokens only. The visual foundation is token-driven and must support light and dark themes equally.
