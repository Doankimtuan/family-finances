# artifacts/

All **produce packs** (project/product outputs). Framework control-plane packages live under `core/packages/`; quality gates under `governance/`.

| Pack family | Examples |
|-------------|---------|
| Product RE | `knowledge/`, `features/`, `business/`, `product-architecture/`, `product/`, `workflow/`, `requirements/`, `acceptance/`, `gaps/` |
| Solution Architecture | `architecture-v2/`, `tech-stack/`, `migration/`, `folder-structure/`, `redesign/` |
| Specification | `repository/`, `specifications/`, `tasks/`, `roadmap/`, `implementation/` |
| Validation outputs | `validation/`, `reports/`, `scores/`, `execution/` |

Logical consume alias: product architecture notes are **`artifacts/product-architecture/`** (never AIOS `docs/architecture/`).
