# Examples — `acceptance-criteria-generator`

Non-normative illustrations for humans scaffolding a worker.

## Rules

1. Examples MUST NOT be treated as conformance tests (see `../testcases/`).
2. Use fake but well-formed `art_…` ids.
3. Show the shape of inputs the worker expects after claim/prepare.
4. `sample-primary-payload.json` is the illustrative primary payload for `acceptance-criteria`.

## Files

| File | Purpose |
|------|---------|
| `sample-input.json` | Claimed-run + task context including consume inputs |
| `sample-output.json` | Envelope illustration |
| `sample-primary-payload.json` | Domain-flavored primary payload (Family Finances) |
