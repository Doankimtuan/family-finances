# Reviewer — product-re-coverage-review

Qualitative coverage review for Product RE primary payloads (ingest, transform, gap).

## Rubric themes

- Traceability via `source_paths`
- Fidelity to implementation-as-is
- Type-fit (personas / steps / SHALL / GWT / ingest kinds)
- No invention / redesign

## Veto

- Redesign or Feature Worker proposals
- Using `ai-os/architecture/` as product architecture input

## Non-goals

Does not replace `product-re-schema-check`. Side effects: none (review artifact only).
